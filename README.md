# 崩老头 AI Skill

一个用于模拟“高频关系运营”的 AI Skill。

它不鼓励诈骗，也不是自动化养号工具。

这个项目试图把互联网热梗“崩老头”抽象成一种：

- AI relationship simulator
- 社交策略分析器
- 情绪劳动减负工具
- 人设运营观察器

---

## Features

- 分析老头画像
- 判断关系阶段
- 识别风险信号
- 生成聊天回复
- 提供关系运营建议
- 模拟“高频情绪劳动”

---

## Trigger Words

- 崩老头
- 用崩老头视角分析
- 这个人值不值得聊
- 帮我回复
- 帮我维持聊天
- 怎么拿捏

---

## Example

输入：

> 58岁，离异，做工程，经常给我发红包，但从不明确关系。

输出：

- 人物画像
- 风险等级
- 情绪需求
- 推荐聊天节奏
- 示例回复
